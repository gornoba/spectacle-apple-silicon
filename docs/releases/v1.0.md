# Spectacle Apple Silicon ver 1.0

원본 Spectacle을 Apple Silicon 맥에서 Rosetta 없이 arm64로 실행하도록 전환한 비공식 첫 릴리스입니다. 이 프로젝트의 `1.0`은 원본 Spectacle의 버전 번호와 별도입니다.

## 다운로드

**Assets → `spectacle_apple_silicon_ver_1.0.zip`**을 받으세요. ZIP을 풀면 `Spectacle.app` 하나가 나옵니다. `Source code (zip)`은 실행 앱이 아닙니다.

- Apple Silicon / arm64 전용, 빌드 지원 하한 macOS 13.
- 절반·모서리·가운데·최대화, 크기 순환, 3분할, 확대·축소, 다중 모니터, Undo/Redo 유지.
- 기존 단축키 JSON과 환경설정 형식 유지.
- Sparkle·앱 내 업데이트 제거, ZIP 수동 업데이트.
- 로그인 실행을 `SMAppService`로 전환.
- 최신 AppKit의 설정 입력칸 그리기 문제 수정.
- 원본 MIT 라이선스를 앱 내부에도 포함.

## 설치

기존 앱과 설정을 백업하고 Spectacle을 종료한 뒤 새 앱을 `/Applications`로 옮깁니다. 시스템 설정의 손쉬운 사용에서 현재 앱을 허용하세요. 이전 서명의 권한이 남았다면 현재 설치 앱을 다시 추가해야 할 수 있습니다. 자세한 사용법은 [한국어 README](https://github.com/gornoba/spectacle-apple-silicon#readme)를 참고하세요.

## 검증 범위

버전 1.0의 빌드·패키지 검사와 XCTest 결과는 저장소의 검증 문서를 참고하세요. 기능 코드는 기존 개발 검증본과 같으며, 해당 코드에서 Apple M2 / macOS 26.6.2의 실제 단축키·메뉴·다중 모니터와 설정 보존을 확인했습니다. 버전 1.0 패키지 자체의 새 설치·실행, 실제 재로그인 자동 실행, macOS 13 실기기, 다른 Mac에서의 다운로드 설치는 별도 미검증입니다.

## 서명 및 출처

**ad-hoc 서명이며 Developer ID 서명·Apple 공증은 없습니다.** macOS가 다운로드한 앱을 차단할 수 있습니다. 출처를 확인한 뒤 Apple의 공식 보안 안내를 따르세요.
